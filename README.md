# گزارش عملیات حذف فایل‌ها

این پروژه یک برنامهٔ کوچک FastAPI برای گزارش‌دادن وضعیت درخواست حذف فایل‌هاست.

## اجرا

نقطهٔ ورود برنامه `app.main:app` است:

```text
uvicorn app.main:app
```

مسیرها:

- `GET /health` — بررسی سلامت سرویس
- `GET /` — رابط وب فارسی
- `GET /api/status` — گزارش JSON قابل بررسی

## وضعیت ایمن حذف

درخواست «همه فایل‌ها را حذف کن» تا دریافت تأیید انسانی دربارهٔ محدوده و استثناها اجرا نمی‌شود. برنامه هیچ فایل یا پوشه‌ای را حذف یا تغییر نمی‌دهد و وضعیت را با `operation_state` برابر «در انتظار تأیید دامنه و استثناها» گزارش می‌کند.

`/api/status` یک inventory واقعی از تمام ورودی‌های زیر ریشهٔ پروژه تولید می‌کند و آن را جداگانه در `pre_operation_inventory` و `remaining_items` نمایش می‌دهد. فایل‌های مخفی نیز در این محدوده شمرده می‌شوند؛ وابستگی‌ها و فایل‌های تولیدشده فقط در صورت قرارداشتن زیر ریشه شمرده می‌شوند. مسیرهای خارج از ریشه هرگز مشمول عملیات نیستند. فایل‌های `app/main.py` و `app/__init__.py` برای حفظ قرارداد ASGI و نقطهٔ ورود `app.main:app` استثنا هستند.

در وضعیت فعلی `deleted_items` همیشه خالی و `deletion_performed` همیشه `false` است؛ این رفتار تا تأیید صریح دامنه و استثناها حفظ می‌شود.
