# فرم فارسی درخواست وام

یک برنامهٔ کوچک FastAPI برای نمایش فرم راست‌چین درخواست وام است. اطلاعات در جایی ذخیره نمی‌شوند و endpoint پس از اعتبارسنجی فقط پیام موفقیت برمی‌گرداند.

## مسیرها

- `GET /` صفحهٔ فرم HTML
- `GET /health` پاسخ سلامت JSON
- `POST /api/loan-requests` دریافت اطلاعات فرم به‌صورت JSON

## اجرا و تست

ورودی برنامه `app.main:app` است. برای اجرای محلی، در محیطی که FastAPI و Uvicorn در دسترس هستند، از اجرای ASGI استاندارد استفاده کنید. تست‌ها با دستور زیر اجرا می‌شوند:

```text
pytest
```

فایل `requirements.txt` فقط فهرست مستند وابستگی‌های مجاز پروژه است.
