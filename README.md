# Minimal FastAPI Application

این پروژه عمداً به حداقل فایل‌های لازم کاهش یافته است. درخواست حذف فایل‌های پایتون هنوز دامنهٔ صریحی ندارد؛ بنابراین در این مرحله هیچ فایل `.py` حذف نشده است.

## گزارش فایل‌های پایتون و وابستگی‌ها

فایل‌های موجود:

| فایل | importها | وضعیت |
|---|---|---|
| `app/main.py` | `fastapi.FastAPI`، `fastapi.responses.HTMLResponse`، `pydantic.BaseModel` | برای اجرای `app.main:app` ضروری است |
| `tests/test_main.py` | `fastapi.testclient.TestClient`، `app.main.app` | فایل تست؛ برای اجرای برنامه ضروری نیست، اما فقط با تأیید صریح قابل حذف است |

نقطهٔ ورود ASGI، `app.main:app`، به `app/main.py` وابسته است. فایل پایتونی اضافی یا بلااستفاده‌ای خارج از این دو فایل شناسایی نشده است.

## وضعیت تصمیم حذف

**تصمیم کاربر هنوز دریافت نشده است.** برای اجرای حذف، کاربر باید صریحاً یکی از این دامنه‌ها را تأیید کند:

1. حذف همهٔ فایل‌های `.py`؛ یا
2. حذف فهرست مشخصی از فایل‌ها، مانند `tests/test_main.py`.

تا زمان دریافت این تأیید، هیچ فایل پایتونی حذف نمی‌شود.

حذف همهٔ فایل‌های پایتون با الزام حفظ برنامهٔ FastAPI و نقطهٔ ورود `app.main:app` ناسازگار است. چنین حذفی یک تغییر معماری محسوب می‌شود و پس از آن import نقطهٔ ورود، اجرای ASGI و تست‌های وابسته به Python شکست خواهند خورد.

## اجرا

```text
uvicorn app.main:app
```

## بررسی سلامت

```text
GET /health
```

پاسخ موفق:

```json
{"status":"ok"}
```

## اجرای تست‌ها

```text
pytest
```

نقطهٔ ورود ASGI: `app.main:app`
